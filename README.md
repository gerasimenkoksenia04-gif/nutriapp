# NutriApp

### *Healthy habits start here.*

---

## About
NutriApp is a web and mobile application designed to support balanced nutrition and healthy lifestyle habits.

### Key features:
- Daily calorie and macro calculator (Protein / Fat / Carbs)
- Micronutrient deficiency symptom analysis
- Food recommendations based on nutrient synergy
- Daily nutrition diary with progress tracking

## Setup

Make sure to install dependencies:

```bash
npm install
```

Build the application for production:

```bash
npm run build
```

Locally preview production build:

```bash
npm run preview
```
